# Contribuir

- Abre uma issue com o problema, o nicho e a plataforma.
- Pull requests bem-vindos: novos estilos de edição, traduções do banco de perguntas, melhorias aos estágios, scripts.
- Regras: nenhum dado pessoal de criadores; fontes e datas em tudo o que seja "o que funciona"; sem texto, imagens ou áudio protegidos; ficheiros em UTF-8; linguagem clara.
- Testa os scripts em `scripts/` antes de abrir PR.
