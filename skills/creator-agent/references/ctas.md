# CTAs

Última verificação: 2026-10-07

| Fase | CTA | Notas |
| --- | --- | --- |
| Topo | "Segue para a parte 2", "Partilha com alguém que precisa" | Um só CTA |
| Topo ou meio | "Comenta [PALAVRA] e envio-te o guia" | Exige ferramenta de DM e consentimento (RGPD na UE) |
| Meio | "Subscreve", "Entra na newsletter", link para o vídeo seguinte | Verbal e no ecrã |
| Fundo | "Entra na lista de espera", "Marca uma chamada", "Link na bio" | Comentário fixado com o link |
| Podcast | "Deixa a tua pergunta para o próximo episódio" | Gera conteúdo futuro |

Regras: um CTA por vídeo; nunca prometer ganhos garantidos; urgência só se for real; o CTA tem de corresponder ao que o vídeo prometeu.
