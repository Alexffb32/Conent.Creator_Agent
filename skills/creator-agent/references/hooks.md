# Ganchos

Última verificação: 2026-10-07 (atualizar com pesquisa; padrões gerais, sem dados de nenhum criador)

O gancho tem de funcionar em menos de 3 segundos, falado e escrito no ecrã.

| Padrão | Estrutura | Exemplo (adaptar ao nicho) |
| --- | --- | --- |
| Oportunidade | "Se és [perfil] e queres [resultado], faz isto" | "Se tens 18 anos e queres ganhar dinheiro sem faculdade, ouve isto" |
| Contra-senso | Nega uma crença comum | "Não precisas de mais disciplina, precisas de menos opções" |
| Erro comum | "O erro que [perfil] comete" | "O erro que faz 90% desistir ao fim de 2 semanas" (só com dado real) |
| Número concreto | Resultado ou prazo real | "O que mudou em 30 dias" (só com dados confirmados) |
| Bastidores | Mostra o processo | "Isto é um dia normal a construir [projeto]" |
| Dois lados | Debate | "[Opção A] ou [opção B]: o que escolhia" |
| Segredo ou atalho | Promete poupar tempo | "O método mais simples para [tarefa]" |
| Loop | A última frase liga à primeira | Termina com a pergunta do início |

Testar: usar 2 padrões durante 2 semanas, comparar retenção aos 3 s, manter os melhores.
