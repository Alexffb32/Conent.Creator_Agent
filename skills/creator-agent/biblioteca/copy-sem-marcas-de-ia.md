# Copy sem marcas de texto gerado

Adaptado ao português europeu a partir de `skills/copywriting/references/ai-tells.md` do repositório coreyhaines31/marketingskills (MIT, ver `CREDITOS.md`). O que importa é a forma do texto, mais do que as palavras: um rascunho pode evitar todas as palavras proibidas e ainda assim soar a máquina.

Legenda: PROÍBE = é uma marca mesmo uma vez; LIMITE = aceitável uma vez, marca quando se repete ou se empilha.

| Padrão | Regra | Exemplo a evitar | Como reescrever |
| --- | --- | --- | --- |
| Revelação por contraste ("não é X, é Y") | PROÍBE | "O teu outreach não falha na mensagem. Falha no que encontram quando te pesquisam." | Dizer Y direto com a razão: "Quem recebe a tua mensagem pesquisa o teu nome antes de responder." |
| Lista de negações ("sem X, sem Y, sem Z") | PROÍBE | "Sem contrato, sem taxas, sem complicações." | Dizer o que acontece: "Começas esta semana e pagas só o que usas." |
| Cauda acumulada (frase fechada + fragmento a reforçar) | PROÍBE | "Faço o teu site. Rápido. Claro. Eficaz." | Uma frase com um facto |
| Pergunta retórica seguida da resposta | PROÍBE | "O que muda? Tudo." | Afirmar o facto |
| Revelação com dois pontos | PROÍBE | "A verdade é simples: ninguém te conhece." | Começar pela afirmação |
| Staccato de fragmentos | LIMITE: um por secção | "Mensagem. Resposta. Reunião." | Uma frase corrida |
| Tríades automáticas | LIMITE: uma por secção | "claro, rápido e eficaz" (sem prova de nenhum) | Só três quando há mesmo três coisas |
| Travessões | PROÍBE em texto curto (e o Alex não os usa no ecrã) | | Vírgula, dois pontos ou frase nova |
| Ritmo uniforme (todas as frases do mesmo tamanho) | LIMITE | | Variar o comprimento |
| Sujeitos abstratos ("a presença digital permite...") | LIMITE | | Pôr uma pessoa a agir: "o cliente pesquisa..." |
| Sinónimos em rotação (cliente, utilizador, consumidor, público) | LIMITE | | Repetir o termo certo |
| Falsos intervalos ("de sites a funis a marcas") | LIMITE | | Listar o que é |

## Autoverificação antes de entregar um guião, legenda ou CTA
1. Há algum "não é X, é Y" ou "sem X, sem Y"? Reescreve.
2. Cada afirmação tem um facto, um número real ou um exemplo? Se não, corta.
3. A primeira frase faz sentido sozinha? (Instagram corta a legenda aos cerca de 125 caracteres.)
4. Lê em voz alta: soa a ti ou a anúncio?
Para o resto (vocabulário inflacionado, aberturas genéricas), usa a skill `avoid-ai-writing` ou a `ig-humanizer`.
