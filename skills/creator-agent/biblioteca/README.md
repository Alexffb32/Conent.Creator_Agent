# Biblioteca

O que o agente reutiliza em todos os criadores. Só conteúdo geral: nada de dados privados de criadores, e só ficheiros que se podem partilhar.

| Ficheiro | O que tem |
| --- | --- |
| [componentes.md](componentes.md) | Os componentes de motion do `compor.py` (gancho, palavra, lista, número, notificações, pesquisa, mosaicos, lower third, remate, CTA), estilos de legenda e o resto do config, com exemplos |
| [estilos/](estilos/) | Fichas de estilo de edição (como fazer uma e as que já existem) |
| [sons.md](sons.md) | Tipos de SFX, níveis em relação à voz, catálogo dos sons do criador e kit gerado |
| [musica.md](musica.md) | A música composta por código, regras de mistura e como usar música do criador |
| [ideias.md](ideias.md) | Formatos por fase do funil, com os componentes que ajudam |
| [prompts.md](prompts.md) | Pedidos prontos para o criador e checklists do agente em cada momento |

Para acrescentar: segue o formato do ficheiro, põe data e fontes no que for "o que funciona", e propõe por pull request (ver `CONTRIBUTING.md`).

## Pesquisa
`pesquisa/` guarda a pesquisa de 2026-10-09 com fontes, datas e confiança (ganchos e CTAs, funil e auditoria, roadmap das contas, medições do Iman Gadzhi, melhorias do próprio agente). Ver `pesquisa/README.md`.
