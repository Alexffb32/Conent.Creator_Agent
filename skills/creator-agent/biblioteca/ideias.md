# Banco de formatos e ideias

Formatos que se repetem em qualquer nicho, por fase do funil. São estruturas para adaptar, não textos para copiar.
Escolhe pela fase que o `proximo-post.py` indicar e pelo que o criador consegue gravar. Os ganchos estão em `references/hooks.md`, os CTAs em `references/ctas.md`.

## Topo (alcance)
| Formato | Estrutura | Componentes que ajudam |
| --- | --- | --- |
| Erro comum | gancho com o erro, porque acontece, o que fazer em vez disso | `palavra` (o erro), `lista` (o que fazer) |
| Mito contra realidade | "dizem X", "na verdade Y", prova ou exemplo | `palavra` com MITO e REALIDADE |
| Lista rápida | "3 coisas que…" com um exemplo cada | `lista`, `numero` |
| Antes e depois | situação antiga, mudança, resultado | `notificacoes` (antes), `numero` (depois) |
| Opinião forte | tese, porque, a exceção | `gancho`, `remate` |
| Tendência no nicho | o que está a acontecer, o que significa para quem vê | `pesquisa`, `mosaicos` |

## Meio (confiança)
| Formato | Estrutura | Componentes que ajudam |
| --- | --- | --- |
| Tutorial em passos | problema, 3 a 5 passos, resultado | `lista`, `pesquisa` |
| Bastidores | o que estou a fazer, porquê, o que aprendi | `lower_third`, `mosaicos` |
| Caso real | cliente ou projeto (com autorização), problema, processo, resultado | `notificacoes`, `numero` |
| Desmontar um exemplo | pega num site, perfil ou anúncio e mostra o que funciona | `pesquisa`, `lista` |
| Pergunta da audiência | pergunta de um comentário, resposta completa | `cta` (comenta a tua pergunta) |
| Série | episódio N de um tema fixo | o mesmo gancho visual em todos |

## Fundo (conversão)
| Formato | Estrutura | Componentes que ajudam |
| --- | --- | --- |
| Prova | resultado confirmado, como se chegou lá, como ter o mesmo | `numero`, `remate` |
| Oferta clara | para quem é, o que inclui, o próximo passo | `lista`, `cta` |
| Objeção | "não preciso de X porque…", resposta | `palavra`, `remate` |
| Processo de trabalho | como é trabalhar com o criador, passo a passo | `lista`, `lower_third` |

## Como gerar ideias novas
1. Lê os comentários e perguntas do criador (ou pede-lhe 5) e os outliers da última pesquisa (`referencias/`).
2. Cruza cada dor da audiência com 2 formatos desta lista, na fase que o funil pede.
3. Para cada ideia: gancho (padrão de `hooks.md`), formato, componentes, esforço de gravação. Propõe 3 e o criador escolhe.
4. Regista as ideias que não foram escolhidas no `brief.md` para não se perderem.
